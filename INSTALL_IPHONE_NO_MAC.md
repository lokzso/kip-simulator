# Установка KIP & Electrician Simulator v4.1 на iPhone без Mac

## GitHub Pages
1. Открой репозиторий `kip-simulator`.
2. Удали старые файлы, которых нет в чистой сборке v4.1.
3. В корень репозитория загрузи:
   - index.html
   - app.js
   - style.css
   - manifest.webmanifest
   - sw.js
   - README.md
   - INSTALL_IPHONE_NO_MAC.md
   - папку icons
4. Settings → Pages:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: /(root)
5. Дождись публикации.

## iPhone
1. Открой сайт в Safari.
2. Если старая версия ещё открыта — закрой приложение и Safari.
3. Открой сайт снова.
4. Поделиться → На экран «Домой».

## Обновления
Начиная с v4.1 приложение не использует постоянный офлайн-кэш.
В разделе «Обновление» можно нажать «Проверить и обновить».

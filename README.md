# KIP & Electrician Simulator v4.1

Чистая актуальная сборка PWA без старых файлов и мусора.

## Что внутри
- index.html — точка входа приложения
- app.js — вся логика приложения
- style.css — стили интерфейса
- manifest.webmanifest — параметры установки PWA
- sw.js — миграционный service worker, который удаляет старые кэши и сам отключается
- icons/ — иконки приложения
- INSTALL_IPHONE_NO_MAC.md — установка на iPhone без Mac

## Важно для обновления с GitHub Pages
Загружай содержимое ЭТОЙ папки прямо в корень репозитория.

В корне GitHub должны лежать только:
- index.html
- app.js
- style.css
- manifest.webmanifest
- sw.js
- README.md
- INSTALL_IPHONE_NO_MAC.md
- папка icons

Не оставляй рядом старые архивы, старые версии app.js/style.css, дополнительные index-файлы и старые service worker.

## v4.1
В этой версии:
- убран постоянный офлайн-кэш;
- старые service worker автоматически удаляются;
- Cache Storage очищается при первом запуске;
- app.js/style.css/manifest загружаются с version-параметрами;
- кнопка «Обновление» принудительно получает свежую версию;
- обновления на iPhone должны идти напрямую с GitHub Pages.

## После загрузки на GitHub
1. Удали старые файлы из репозитория, которых нет в этой чистой сборке.
2. Загрузи все файлы из этой папки в корень репозитория.
3. Дождись зелёной галочки GitHub Pages.
4. На iPhone открой сайт через Safari.
5. Один раз перезапусти установленную PWA.

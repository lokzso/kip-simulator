# KIP & Electrician Simulator v4.2 CLEAN

Чистая актуальная сборка.

## Новое в v4.2
- анимация прохождения тока по проводам;
- свечение элементов под напряжением;
- вращение двигателя;
- анимация реле и контакторов;
- LED-индикация ПЛК;
- анимация клапана;
- анимация насоса, потока и жидкости в баке;
- плавные переходы интерфейса;
- визуальная реакция на успешную/ошибочную проверку;
- изменение параметров настраиваемых приборов;
- датчики 4–20 мА и 0–10 В пересчитывают сигнал автоматически;
- можно менять сопротивление резистора;
- напряжение источника;
- номинал катушки реле/контактора/клапана;
- ток автомата, предохранителя и теплового реле;
- мощность и обороты двигателя;
- диапазоны AI/AO;
- сохранены функции v4.1 для более надёжного обновления на iPhone.
